# Treact landing-page practice

A static HTML/CSS/JavaScript landing-page practice project based on a Treact-style layout. The root index.html references style.css, index.js, and local assets.

## Project status

Learning / portfolio archive. The documentation describes only files that could be verified in the repository root.

## Getting started

Open `index.html` in a web browser. No npm installation is required for the checked-in static page.
